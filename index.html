What it does

Everything GitHub
forgot to add

A lightweight browser extension that adds power-user file management directly into the GitHub UI.

Multi-file Select
Click Select to enter selection mode. Checkboxes appear next to every file and folder — pick as many as you need across the current directory.
Bulk Delete
Select files and hit Delete. A confirmation modal shows the full list, then opens each file's GitHub delete page in a separate tab — 350ms apart so your browser doesn't choke.
Copy File Paths
Copies the full repo-relative paths of every file in the current directory to your clipboard in one click. Newline-separated and ready to paste into scripts or commit messages.
Repo Stats + Commit Heatmap
Shows total files, folders, and a top-10 file-type breakdown with bar charts. Also fetches and renders a full GitHub-style commit activity heatmap for the past year — with hover tooltips.
Select All / None
Toggle every item in the current directory instantly. All and None buttons sit right in the toolbar so bulk-selecting a whole folder takes a single click.
File Page Quick Actions
On any individual file page, adds inline Edit, Raw, Blame, History, Copy path, and Delete buttons right next to the existing GitHub toolbar — no extra clicks to find them.
Delete Repo Auto-fill
When GitHub's repo-deletion dialog opens, an Auto-fill button appears that types the required confirmation text for you — toggle it on or off without refreshing.
Non-destructive & Auto-reinject
Exiting select mode fully restores GitHub's original DOM. The extension also watches for GitHub's SPA navigation and re-injects its buttons automatically on every page transition.
