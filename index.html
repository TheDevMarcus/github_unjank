What it does

Everything GitHub
forgot to add

A lightweight browser extension that adds power-user file management directly into the GitHub UI.

Multi-file Select
Click Select to enter selection mode. Checkboxes appear next to every file — pick as many as you need.
Bulk Delete
Select files and hit Delete. Opens each file's delete page in tabs so you can confirm and remove in bulk.
Copy File Paths
Copy the full paths of all selected files to your clipboard with one click. Perfect for scripts and commits.
Repo Stats
See a breakdown of file types and counts at a glance right on the main repo page. Know your codebase instantly.
Select All / None
Toggle every file in the current directory with a single click. All and None buttons keep things fast.
Non-destructive
Exit select mode at any time. The extension cleans up after itself and restores GitHub's original DOM completely.
